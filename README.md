# Beds24 ダッシュボード

予約・売上・リスティングの問題点を一つの画面でまとめて確認するための、簡易Webダッシュボードです。

## セットアップ手順

1. Python 3.10 以上が入っていることを確認してください。

   ```bash
   python3 --version
   ```

2. 依存パッケージをインストールします。

   ```bash
   cd /Users/tomo/Documents/beds24-dashboard
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. `.env.example` をコピーして `.env` を作成し、Beds24の招待コードを貼り付けます。

   ```bash
   cp .env.example .env
   ```

   `.env` をテキストエディタで開き、`BEDS24_INVITE_CODE=` の後ろに招待コードを貼り付けて保存してください。
   招待コードは Beds24 管理画面の「設定 > アカウント > アクセス」から発行できます。

   > 招待コードは一度使うと自動的に `BEDS24_REFRESH_TOKEN` に置き換わり、`.env` に保存されます。
   > 2回目以降の起動では招待コードは不要です。

4. アプリを起動します。

   ```bash
   streamlit run app.py
   ```

   ブラウザが自動的に開きます(開かない場合は表示されたURLをコピーしてアクセスしてください)。

## 画面構成

- **予約タブ**: 選択した期間のチェックイン予定の予約一覧
- **売上タブ**: 月別・物件別の売上グラフ
- **リスティング問題点タブ**: 物件名・説明文・写真が未設定の物件を検出

## 注意事項

- `.env` にはAPIの認証情報が入るため、他人と共有したりGitにコミットしたりしないでください(`.gitignore` 済み)。
- Beds24 APIのレスポンス構造は実際のデータで確認しながら微調整が必要な場合があります。各タブ下部の「生データを見る」で実際のJSONを確認できます。
